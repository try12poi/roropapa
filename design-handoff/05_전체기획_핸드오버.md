## 3. 게임 컨셉 상세 (피치 v2 기준)

### 3.1 세계관 규칙 — "해의 법칙"
좀비는 해를 싫어한다. 이 규칙 하나가 게임 전체를 설명한다:
1. 낮의 야외 = 비교적 안전한 파밍 구간
2. 물자가 있는 실내 = 어둠 속 좀비와의 교전 지역 (미니 던전)
3. 해가 지기 전에 귀환하지 못하면 깨어난 호드 전부와 만난다 (일몰 타이머)

### 3.2 코어 루프 — 하루가 한 판 (목표 세션 15~20분)
```
낮(원정: 파밍·구출·일몰 타이머) → 밤(웨이브 방어: 배치·바리케이드) → 아침(정산·건설·배급·방출 결정) → D+1
```
- 매일 아침 해가 뜨는 것이 클리어 연출. 생존 일수 D+n이 곧 명예(리더보드).
- 복잡도는 순차 개방으로 해결: D+1~3 밤 방어만 → D+4 원정 해금 → D+7 경영(배급·방출) 개방.

### 3.3 무대 — 단독건물 안심24 (3층 구조)
- **옥상**: 감시탑·텃밭·라디오 안테나 (저격 거점)
- **1층 매장**: 밤 방어전 무대. 매대=엄폐물, 셔터+바리케이드. 붕괴=게임 오버
- **지하 벙커** (점장의 유산, 카드키 해금): 물자고·무기고·발전기실·침실·추모벽·**최심부(끝까지 잠김 — 시즌 스토리의 문)**. 카드키 권한 등급 = 성장 트리의 서사화
- 물자 게이지 = 생존 타이머: 벙커 비상물자는 2인 기준 14일치. 인원이 늘수록 시계가 빨라진다 → 파밍이 곧 생존

### 3.4 생존자 시스템 — 이 게임의 심장
- **3계층**: 코어 5인(불사, 중상만) / 합류 생존자 32인(영구 사망 → 추모벽 폴라로이드) / 방출자(약탈자 or 은인으로 재등장 — 방출 당시 대우로 분기)
- **3상태**: 전투 배치(슬롯 제한) / 시설 근무(직업별) / 휴식 대기 — "1명 = 전력 +1 = 식량 소모 +1"
- **구출 판단**: 원정 중 발견한 생존자의 정보 카드(직업·능력·나이·식량 소모·단점)를 보고 그 자리에서 결정
- **단점 시스템**: 합류 생존자 전원 장점 1+단점 1. 숨겨진 단점(구출 후 발각) / 상쇄 콤보(다른 생존자·시설로 관리) / 극복 이벤트(스토리)
- **직업 조합 콤보**: 소방관+집배원=구조 작전, 조리사+화훼농원+주부=자급자족 등 도감 "???" 숨김 6종+
- **방출의 서사**: 내보낸 회계사가 D+23 약탈자로 돌아온다 — 죄책감이 리텐션이 되는 설계

### 3.5 소음 게이지 (v1 소문 게이지 이식)
무기 2계열: 편의점 물품(조용·약함) vs 벙커 화기(강력·시끄러움). 소음이 높을수록 웨이브가 커진다 — 매 전투가 리스크 베팅.

## 4. 프로토타입 구현 명세 — game-v2 (2026-08-06 빌드)

> 기획서가 아니라 **실제로 돌아가는 코드의 수치**다. 전 수치는 `gamev2.js` 상단 CFG와 각 시스템 테이블에 있으며 즉시 조정 가능.

### 4.1 기술 스택
- 순수 JavaScript + Canvas 2D, 외부 라이브러리 0, 단일 html 파일 (이미지 base64 내장). 세로모드, 키보드(WASD)+터치 가상 조이스틱 동시 지원.
- 빌드: `python3 build.py` — JS 템플릿에 이미지 8종 주입, 플레이스홀더/블롭 검증 포함.
- 맵은 좌표 데이터(43개 오브젝트: 벽·문·창문·사물·사다리·벙커입구)로 정의, `wall_editor`로 제작.

### 4.2 씬 구조 (3씬)
- **1층 매장**: 본전투. 맵 아트 v5 위에 충돌·시야(LOS)·출입구 시스템
- **옥상**: ㄱ자 발자국 정확 반영, 저격 거점(원거리 전용 최대 3인), 보급상자, 해치로 1층 연결
- **지하 벙커**: 6개 방(저장고·입구계단·무기고·공용거실·침실 12인·기계실) + 금고문(최심부 — 빨간 불, 미개방)

### 4.3 밤 방어 (코어 전투) — 90초 = 03:00~06:00
- **AI 길찾기**: 좀비는 flow-field(BFS 거리장)로 벽을 우회해 출입구로 몰림. 바리케이드가 살아있으면 문을 갉고(기본 2.4/s + 날마다 +0.4), 뚫리면 진입(창문은 1.8초 등반). 이미 뚫린 문을 강하게 선호(+260 비용 페널티)해 자연스러운 "뚫린 곳으로 몰림" 발생.
- **공격 시야(LOS)**: 벽 관통 공격·사격 불가. 창문은 쏘는 구멍(사격 가능, 통행 불가).
- **좀비 스케일링**: HP 32 + 8×일차 + 0.22×경과초 / 속도 42+랜덤12+2×일차 / 스폰 간격 1.35초 시작, 밤 경과·일차에 따라 최소 0.34초까지 단축.
- **거점 배치 (타워디펜스식)**: 외부 연결 출입구만 자동 판별(내부 문 제외)해 거점화. 거점당 최대 3인, 옥상은 원거리 전용. 배치 화면에서 콤보 실시간 미리보기.
- **동료 AI**: 거점 요격 반경(근접 210 / 원거리 240+) 안 좀비를 능동 요격, 이탈 한계(STRAY) 넘으면 복귀. 만수는 좀비 없으면 자동 수리(14/s). 다운되면 10초 후 자력 기상(서연 근처면 3.8배 가속 + 체력 75% 기상).
- **직업 콤보 4종** (배치 시너지, 자동 발동):
  | 콤보 | 조건 | 효과 |
  |---|---|---|
  | 협공 | 같은 거점 근접 2인 | 근접 대미지 ×1.25 |
  | 엄호사격 | 같은 거점 근접+원거리 | 원거리 연사 ×1.33, 근접 대미지 ×1.15 |
  | 십자포화 | 옥상 원거리 2인 | 사거리 +80, 대미지 ×1.2 |
  | 요새 | 만수를 거점 배치 | 해당 거점 내구 +40·완충 |
- **서연(플레이어)**: 치료 오라(반경 100, 18/s), 빠루 근접(대미지 30, 쿨 0.72s), 수리(8/s), 레벨업 3택(카드 6종: 공격력·공속·범위·이속·최대체력·응급보수).
- **드랍**: XP젬(82%) / 식량(10%) / 구급약(8%) — 자석 반경 60.

### 4.6 낮 원정 (거리=시간 노드맵)
