## 2. 밤 방어

### 2.1 공간·거점
- 무대: 1F 매장(맵 v5 좌표 데이터 `collision_data_v5.json` — 벽/문/창문/사물/사다리/벙커입구). 외부와 연결된 문·창문만 자동 거점화(프로토의 perimeter BFS 판별 로직 정본).
- 거점당 배치 상한 3인. 옥상 거점은 원거리 전용. **만수는 옥상 배치 불가(고소공포)**, 미성년은 모든 전투 거점 불가.
- 바리케이드: 거점별 내구(31번 §3). 좀비가 갉음. 파괴 시 통과(창문은 등반 1.8초). 수리: 서연·만수·근무 인원.

### 2.2 좀비 AI (프로토 정본)
1. 스폰: 맵 가장자리(상·좌·하) → 목표 출입구 flow-field(BFS 거리장, 24px 그리드) 이동. 벽·가구 우회.
2. 출입구 선택 비용 = (좀비→문 거리) + (문→목표 사람 거리) + (바리케이드 생존 시 +260) → **뚫린 문으로 몰리는 습성** 자동 발생.
3. 진입 후: 가장 가까운 사람 추격. 공격은 접촉, LOS 체크(벽 관통 금지, 창문=사격 가능/통행 불가).
4. 파문 반응: 소음 링(§2.5)에 닿으면 현재 목표를 파문 발원지로 갱신(신규 스폰 아님).

### 2.4 변종 4종 (등장일·수치 31번 §2.3)
- **러닝크루(러너)**: 직선 질주, 바리케이드 무시하고 창문 직행. 낮은 HP.
- **이삿짐(브루트)**: 갉기 5배·넉백 면역·저속. 호드의 주포.
- **배달통(부머)**: 사망 시 국물 폭발 — 반경 내 좀비 8초 가속. 원거리 처리 유도.
- **우는 놈(위처)**: 원정 실내 전용. 비활성(무해·우회 가능) → 파문 접촉 시 폭주 + 그 건물 전체 어그로.

### 2.5 소음 — 파문 시스템
- 소음 행동마다 **파문 링**이 발원지에서 확산(시각화 필수 — 이것 자체가 튜토리얼). 링에 닿은 좀비·위처가 반응.
- 이중 구조: ① 즉발 = 파문 어그로 ② 누적 = 밤 소음 점수 → **다음 밤** 스폰량 보정(+1%/10점, 상한 +30%). 소음원별 수치 31번 §4.
- 역이용: 전자레인지 "띵"(대형 파문, 피해 없음) = 유인 도구. 유아리 아리아 = 광역 유인 궁극기.

### 2.6 전투 규칙
- 플레이어(서연): 이동만 조작(WASD/가상 조이스틱), 자동 근접(사거리 내 최근접, LOS), 치료 오라, 거점 근처 간이 수리.
- 동료 AI: 거점 요격 반경(ENGAGE) 내 위협 요격, 이탈 한계(STRAY) 초과 시 복귀, 위협 없으면 홀드 지점 대기(프로토 정본).
- **수리 등급** 【08-13 확정 — 수리공의 가치】: 바리케이드 수리는 아무나 못 한다.
  - **A 전문 수리** (위협 없을 때 자동 수리 AI 작동, 100%까지): 만수 14/s · 투안 12/s · 박정철 10/s
  - **B 간이 수리** (상한 50%까지, 느림): 서연 8/s(플레이어 근접 조작) · 조필성 2/s(순찰 중 미세 보수) · 강호구 6/s
  - **불가**: 그 외 전원 — 거점에 서 있어도 수리하지 않는다. 수리공이 없는 밤은 뚫린 문이 뚫린 채로 남는다.
- 직업 콤보(배치 시너지): 협공/엄호사격/십자포화/요새 — 배치 화면에서 실시간 미리보기. 콤보Ⅱ 승급은 성장 연동(§5).
- 궁합(케미): 같은 거점/근무/파티에서 자동 발동(21번 §5 정의, 수치 31번 §7). 도감 "???" 숨김.
- 레벨업 드래프트: XP젬 → 3택 카드(**이번 밤 한정**). 풀 18종 = 서연 6 + 배치 동료 카드 8 + 활성 콤보 카드 4(skilltree_design §6).
- 화살(고주연 전용 탄약): 발사마다 소모. 밤 종료 시 수거(31번 §5). 소진 시 공격 불가(대기 전환).

### 2.7 문 두드리는 소리 (E1, 22번 대본)
- 발동: D+5 이후, 밤당 최대 1회, 확률 25%. 무작위 생존 거점 부근.
- 열기: 해당 바리케이드 15초 개방(좀비 유입 가능) → 무작위 생존자 합류(정보 카드 사후 공개 — 선택 불가가 정체성).
- 무시: 30초 파문 지속 → 다음 아침 유류품 1개 + 팀 사기 -8.

### 2.8 게임오버 — 최후의 저항
1. 트리거: 모든 외곽 거점 바리케이드 파괴 + 매장 내 좀비 수 ≥ 15.
2. 연출: "벙커로 후퇴!" — 코어 전원 벙커 계단 앞 집결(자동 이동), 30초 카운트다운, 배수진 원형 진형.
3. 성공(30초 생존): 강제 새벽 → 다음날은 **매장 탈환전**(특수 밤: 시설 이용 불가, 좀비 소탕이 목표). 실패(서연 포함 전원 다운): 게임 오버 → 기록 화면(D+n·처치·추모벽 롤).
4. 코어 5인 개별 다운은 오버 아님 — 중상 이탈(§4.4). 서연 다운 시 치료 오라 상실 + 사기 -10.

### 2.9 밤 종료 정산 (자동, 새벽 화면)
처치·XP 합산 → SP 지급 → 화살 수거 → 소음 점수 확정 → 부상/감염 판정 → (사망 시 다음 아침 추모 컷 E9).

## 4. 아침 경영

### 4.1 정산 순서(화면 흐름 32번 §3)
① 밤 결과 요약 → ② (사망 시) 추모 컷 → ③ 자원 정산(식량 소모, 생산, 연료) → ④ 이벤트(방출 제안·호드 예고·극복 이벤트 등) → ⑤ 자유 조작(탭: 근무/스킬/장비/시설/지도) → ⑥ 원정 출발 or 밤 준비.

### 4.2 근무 배치
- 상태 3종: 전투(밤 방어+원정 후보) / 시설(생산 — 직업별 배정: 텃밭·주방·작업대·발전기·의무실) / 휴식(완전 회복).
- 근무 슬롯: 시설별 상한(31번 §8), 송인복 보유 시 +1.

### 4.3 사기(팀 모랄) 시스템
- 팀 단일 게이지 0~100, 시작 70. 요인·효과 31번 §9. 임계: 80+ 전 능력 +5% / 40- 공속·수리 -10% / 20- 이탈 이벤트(무작위 1인이 방출 요구 or 무단 이탈 경고).
- 서연(주인공) 생존·활동 자체가 사기 하한 방어(피치의 "팀의 태양").

### 4.4 부상·감염 상태 머신
```
건강 → (밤 피격 누적) 부상: 능력 -30%, 휴식/치료로 해소
건강 → (물림 판정) 감염: 다음 해 뜨기 전 처치 없으면 사망(합류) / 코어는 2일 앓아눕기
    처치: 백인하 수술(성공률 31번 §10, 의료 물자 소모) / 허명지 침(기한 +1일)
전투 중 체력 0 → 다운(10초 후 자력 기상, 서연 근처 가속) — 코어·합류 공통
합류 사망 → 추모벽 등록(E9). 미성년은 사망 없음 — '깊은 방' 이동 + 사기 -10
```

### 4.5 배급·장기 원정 파견 【08-13 개정 — 방출 시스템 폐지】
- ~~방출~~ 폐지. 물자 압박의 답은 사람을 버리는 게 아니라 **사람을 멀리 보내는 것**이다 — 죄책감의 형태가 "내쫓음"에서 "보내놓고 기다림"으로 바뀐다.
- **장기 원정(파견)**: 아침 지도 탭에서 상시 가능(식량 6일 미만이면 시스템이 제안).
  1. 편성 1~3인(전투력 무관, **미성년 동참 가능**), 한내역 게이트로 출발. 기간 2~3일(랜덤).
  2. 파견 중 해당 인원 **식량 소모 0** (단기 압박 해소 효과 = 구 방출의 기능).
  3. **귀환 기본 확률 25%** — 보정: 파티 내 성립 궁합 1개당 +15%p, 무전기 지급(재료 5) +10%p, 식량 지참(3) +5%p, 하동수 포함 +10%p. 상한 80%. (궁합이 좋은 팀일수록 살아 돌아온다 — 궁합 시스템의 최대 활용처)
  4. 귀환 시: 대량 물자 + 사기 +15 + 신규 정보(노드/일지 단서). 수치 31번 §16.
  5. **미귀환 시 후속 롤**(D+7~15 뒤 발생, 31번 §16): 약탈자 전향(꾐에 넘어감 — E3로 습격) / **편의점 위치 노출**(약탈자 무리에게 자백 — 습격 예고 이벤트) / 실종(추모벽 옆 '기다림' 게시판 — 시즌 떡밥) / 뒤늦은 귀환(부상 상태로 셔터를 두드린다 — E1 결합).
  6. 미성년 미귀환은 **사망 없음 원칙 유지** — 항상 '실종' 처리, 이후 구본대(집배원) 구조 미션으로 생환 가능. 단 파견 보낸 순간 사기 −10(어른들의 침묵).
- 배급량 조절(선택): 절반 배급 = 소모 반감 + 매일 사기 −5 + 회복 정지.

## 5. 성장 명세 v2 — 카드키 × 스킬트리 (결정 6 확정판)

### 5.1 카드키 권한 (스토리 수집 → 공간 해금)
| 권한 | 조건(일지 수집) | 열리는 것 | 성장 연동 |

| 1 | 시작(프롤로그) | 벙커 진입·저장고·침실·공용거실 | 기본 수용 인원, 휴식 회복 |
| 2 | 일지 3장 | **무기고** | 진아 화기 트리 해금(이벤트 E6 선행), 벙커 화기 사용 |
| 3 | 일지 7장 | **기계실 풀가동** | 전기 트랩·조명(전성국·만수 시너지), 의무실 개조 → 서연 의료 상위 트리 |
| 4 | 일지 12장 | **최심부** | 탈출 루트(E10), 시즌 지도 |

### 5.2 스킬트리·아이템 강화
- 캐릭터 트리(코어 5인 × 2갈래 × 3티어)와 SP 경제, 아이템 강화 Lv0→3·각성: **`docs/skilltree_design.md` 정본** + 본 문서 §5.1의 선행 조건 오버레이.
- 밤 드래프트(휘발) vs 아침 성장(영구)의 2층 분리 원칙 유지.
- 합류 생존자는 트리 없음 — 궁합·근무·장비로 성장(로스터 관리가 곧 빌드).

## 9. 장비 시스템 — 무기·방어구·적성·세트 【08-13 신설】

### 9.1 슬롯과 개체차
- 전원 **무기 1 + 방어구 1** 슬롯. 코어 시그니처 5종(빠루·소화기·에어소프트건·렌치·핸드트럭)은 '전용 등급' 무기로 이 체계에 흡수.
- **같은 아이템이라도 성능이 다르다 — 상태 4등급**: 낡음(−20%) / 보통(0) / 양호(+15%) / 정비됨(+30%). 파밍 드랍 시 상태 랜덤(31번 §17). 작업대에서 재료로 1단계씩 정비(임순정=방어구, A급 수리공=무기).

### 9.2 적성 — 캐릭터마다 맞는 아이템 (부 캐릭터 전원 포함)
- 캐릭터별 **적성 태그 1~2개** (무기 계열: 날붙이·둔기·자루·활·총·투척·공구 / 방어구 계열: 중장·경장·작업복·제복).
- 적성 일치 착용 = 효과 **+25%** / 전용(시그니처·본인 직업 장비) = **+50%** — 기존 코어 5인의 주인 시너지를 55인 전원으로 일반화. 예: 마동출=날붙이, 고주연=활, 강호구=자루(도끼)+중장, 오세라=제복, 배중식=투척(철가방).
- 55인 전원의 적성 매핑표는 S4 산출물(21번 데이터에 `aptitude` 필드 추가).

### 9.3 세트 호환 — 다른 장비끼리의 궁합
- 무기·방어구에 **세트 태그** — 같은 세트를 함께 착용하면 공·방 +10% + 세트 고유 효과:
| 세트 | 구성 예 | 고유 효과 |
|---|---|---|
| 소방 세트 | 소방 도끼 + 방화복 | 화염·폭발 피해 무효 |
| 주방 세트 | 정육 식칼 + 두꺼운 앞치마 | 처치 시 식량 드랍 +10%p |
| 공구 세트 | 파이프렌치 + 공구벨트 | 수리 속도 +4/s |
| 경찰 세트 | 삼단봉 + 근무복 | 타격 시 15% 기절 |
| 라이더 세트 | 철가방 + 헬멧 | 이동 +10%, 정면 피해 −15% |
- 카탈로그 목표 규모: 무기 24종(편의점 물품 8 — v1 유산 장우산·테이프클리너·전자레인지 부활 / 생활·공구 8 / 전문 5 / 벙커 화기 3) + 방어구 14종. 전체 표 = S4.
