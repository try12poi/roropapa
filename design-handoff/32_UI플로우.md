## 2. HUD 명세

### 2.1 밤 방어 HUD
| 위치 | 요소 |
|---|---|
| 상단 좌 | D+n, **시계(03:00→06:00)** — 3:33/4:44/5:55에 눈금 강조(예고장 역할) |
| 상단 우 | 킬 카운트, 소음 점수(파문 아이콘, 쌓이면 붉어짐) |
| 상단 바 | 거점 상태 스트립: 거점별 바리케이드 미니 게이지(뚫리면 적색 점멸) |
| 중앙 | 파문 링(월드), 콤보 활성 배지(거점 위) |
| 하단 좌 | 가상 조이스틱 (이동만 — 공격 자동) |
| 하단 우 | 서연 HP·XP, 화살 잔량(고주연 배치 시) |
- 레벨업: 화면 정지 + 3택 카드(재입고 버튼 = 보상형 광고 슬롯).

### 2.2 원정 HUD
| 위치 | 요소 |
|---|---|
| 상단 | ☀️ 햇빛 게이지(35% 이하 노을색 경고), 가방 슬롯 n/20 |
| 노드 | 아이콘+거리 비용, 링 색(近녹/中황/遠적), 수색 완료 체크, 정보 공개 노드(한수정) 밑줄 |
| 실내 | 손전등 부채꼴, 파문 링, 퇴로 화살표 |
| 하단 | 파티 초상 3 + HP, 귀환 버튼(항상 노출 — "지금 돌아가면 안전") |

## 3. 아침 허브 (핵심 화면 — 탭 구조)

```
┌ D+12  🍖34(−12/일) 🔩18 ⛽7L  사기 64 ────────┐
│ [정산·이벤트 요약 카드 영역]                    │
│─[근무]─[스킬]─[장비]─[시설]─[지도]──────────── │
│  탭 콘텐츠 (아래 표)                            │
│                                                │
│ [☀️ 낮 원정 출발]      [🌙 바로 밤 준비]        │
└────────────────────────────────────────────────┘
```
| 탭 | 내용 | 조작 |
|---|---|---|
| 근무 | 생존자 리스트(초상·HP·상태·단점 아이콘) | 탭→ 전투/시설/휴식 토글, 시설 배정처 선택. 궁합 성립 시 ★ 미리보기 |
| 스킬 | 코어 5 선택 → 2갈래 트리(세로), SP 잔량 | 노드 탭=습득, 잠금 노드에 해금 조건 표시(권한 연동) |
| 장비 | 시그니처 5종 + 강화 Lv + 각성 조건 진행도 | 캐릭터 탭→아이템 탭=장착, 강화 버튼(재료) |
| 시설 | 바리케이드/텃밭/발전기/의무실/작업대 Lv + 벙커 단면도(권한 잠금 방은 실루엣) | 강화 버튼, 벙커 방 탭=이동 |
| 지도 | 달안동 노드맵 미리보기 + 호드 예고 배너 + 일지 수집 n/12 | 열람 전용 |

## 4. 주요 모달·연출 명세
| 모달 | 구성 | 비고 |
|---|---|---|
| 구출 정보 카드(E5) | 인물 실루엣→초상, 필드 6종, 좌스와이프=지나침/우=데려감 | 숨김 단점 «잉크 번짐» 표기 |
| 문 두드림(E1) | 화면 가장자리 진동 + 선택 2버튼(15초 타이머) | 밤 방어 중 오버레이 — 게임 계속 진행(멈추지 않음이 긴장) |
| 방출(E2) | 대상 선택 리스트 → 확인(담백한 버튼 "내보낸다") → 셔터 연출 → 자막 | 물자 지참 토글 |
| 추모(E9) | 폴라로이드 부착 1컷 + 문구 | 스킵 가능, 열람 시 사기 +5 |
| 호드 예고 | 아침 상단 배너(D-2부터), 우제민 보유 시 거점 마커 | |
| 최후의 저항 | 화면 적색 비네트 + 30s 카운터 + "벙커로 후퇴!" | 성공 시 종소리, 실패 시 암전 |
| 엔딩 롤콜(E10) | 폴라로이드 슬라이드→명단→정산→백미러 컷→차기 지점 티저 | 스킵 불가 구간 20초 이내 |
| 도감 | 궁합/콤보/변종 "???" 카드 | 발견 시 갱신 알림 |

## 5. 편의점 언어 텍스트 규칙 (UI 라이팅)
- 리롤="재입고" / 부활="교대 알바 도착" / 정산="마감 정산" / 상점(향후)="포인트 적립" / 로딩 팁=점장의 일지 어록.
- 버튼은 동사로 짧게("내보낸다", "데려간다", "버틴다"). 시스템 메시지도 생활어(§20번 톤 가이드).

## 6. 접근성·조작 최소 원칙
- 전 화면 원핸드: 주요 버튼 하단 40% 영역. 조작은 끝까지 "이동 + 탭" 두 가지.
- 색약 대응: 거점 상태는 색+아이콘 병행(균열 아이콘). 파문 링은 색 아닌 선 굵기로도 구분.
