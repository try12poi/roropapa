## 1. 호환 규칙 — 3겹 구조 (디테일)

장비 하나의 최종 성능은 3겹의 보정을 곱해서 나온다:

```
최종 성능 = 기본치 × (1+상태) × (1+적성) × (1+세트)
             │         │          │          │
             │         │          │          └ 세트 성립 +10% + 고유 효과
             │         │          └ 적성 계열 일치 +25% / 전용(이름 박힌 장비) +50%
             │         └ 낡음 −20% / 보통 0 / 양호 +15% / 정비됨 +30%
             └ 카탈로그 표의 수치
```

### 1.1 상태 (같은 아이템도 성능이 다르다)
- 파밍 드랍 시 랜덤(낡음 40 / 보통 35 / 양호 20 / 정비됨 5%). 작업대에서 재료 2→3→5로 1단계씩 정비.
- 정비 담당: 무기 = A급 수리공(만수·투안·박정철) / 방어구 = 임순정. **담당자가 없으면 정비 불가** — 수리공·재봉사의 가치가 장비 경제로도 이어짐.

### 1.2 적성 (캐릭터마다 맞는 아이템)
- 모든 캐릭터는 **무기 계열 적성 0~2개 + 방어구 계열 적성 1개**를 가진다(§4 전체 매핑).
- 계열: 무기 = 날붙이·둔기·자루·활·총·투척·설치·공구 / 방어구 = 중장·경장·작업복·제복·보호복.
- 일치 +25%. **전용**(그 사람 이름이 박힌 장비 — 시그니처 5종·직업 장비) +50%. 적성 밖 장비도 착용은 가능(보정 0) — "맞는 옷"을 찾아주는 재미가 목적이지 제한이 목적이 아니다.

### 1.3 세트 (다른 장비끼리의 호환)
- 모든 장비에 **출처 태그**(소방·주방·공구·경찰·배달·시장·병원·학교·벙커·편의점·공단·물가·보호)가 1~2개 붙는다.
- **태그 호환**: 무기와 방어구가 태그 1개를 공유하면 공·방 +10%.
- **명명 세트**(§3): 지정된 짝이면 +10%에 더해 **고유 효과**가 붙는다 — 태그 호환의 완성형. 도감에 "???"로 숨김(궁합과 같은 발견 문법).
- 일부 세트는 "방어구 + 전용 직업"으로 성립하는 **직무 세트**(무기가 없는 지원형 캐릭터의 세트 자리).

### 1.4 계산 예시 (검산용)
- **마동출 + 정비된 식칼 + 가죽 앞치마**: 식칼 기본 22 × 1.30(정비) × 1.25(날붙이 적성) × 1.10(주방 세트) = **39.3** + 처치 시 식량 드랍 +10%p. 낡은 식칼 맨몸이면 22×0.8 = 17.6 — 같은 칼이 2.2배 차이.
- **고주연 + 양호 리커브 활 + 궁도 보호대**: 18 × 1.15 × 1.50(전용) × 1.10(궁사 세트) = **34.2** + 화살 수거 70→80%(세트) →90%(수제 화살 궁합 중첩 시 상한).
- **배중식 + 보통 철가방 + 헬멧 자켓**: 16 × 1.0 × 1.50(전용) × 1.10(라이더 세트) = **26.4** + 이속 +10%·정면 피해 −15%.

## 5. 설계 노트
- **세트 경쟁 구도**: 라이더 세트(배중식 vs 구본대), 주방 세트(마동출 vs 방순임 vs 정한나) — 같은 세트를 원하는 사람이 여럿이라 **장비 분배가 아침 경영의 결정**이 된다.
- **적성 없는 캐릭터(—)는 약점이 아니다**: 그들의 힘은 고유 능력·궁합에 있고, 방어구 한 칸이 생존 보험. 장비 우선순위에서 자연스럽게 밀리는 것까지가 설계(한정 자원 분배).
