## 0. 제출용 한 장 요약 (이 페이지만 인쇄해도 됨)

**한 문장**: *"일상의 소리가 조용히 공포가 되는 게임"* — 한국 편의점 새벽 3시의 ASMR을 그대로 녹음해 두고, 그 위에 시계와 심박만 얹는다.

**다섯 원칙**
1. **실재의 소리** — 형광등 험, 냉장고 컴프레서, 자동문 차임, POS 스캔음, 전자레인지 "띵". 음악보다 **기계가 내는 실제 소리**가 이 게임의 악기다.
2. **같은 소리의 이중 의미** — 자동문 "딸랑"은 평시엔 손님이 오는 소리, 밤엔 **침입 경보**다. 소리를 바꾸지 않고 **상황만 바꿔** 의미를 뒤집는다.
3. **고어 금지** — 비명·뼈 부러지는 소리·피 튀는 소리 없음. 타격은 **"바스락"(비닐)·"퍽"(둔기)** 계열. 12세 등급을 소리로도 지킨다.
4. **소리는 정보** — 3:33/4:44/5:55 시계, 파문, 문 두드림, 사기 붕괴는 전부 **들려야 하는 플레이 정보**다. 무음으로 플레이해도 되도록 시각 대체(파문 링·시계·배너)를 이미 갖고 있고, 소리는 그 위의 확증이다.
5. **침묵도 악기** — 이 게임에서 가장 무서운 순간은 소리가 **멈추는** 순간이다(소등의 밤, 4:44 직전, 최심부 문이 열리는 순간). BGM으로 공백을 메우지 않는다.

**세 개의 시그니처**
| 소리 | 역할 | 스펙 한 줄 |
|---|---|---|
| **딸랑** (자동문 차임) | 평시 = 일상 / 밤 = 경보 / 아침 = 생존 확인 | 2음 차임. 음정은 현장 실측 후 확정할 것(가안 1,300·1,750Hz). 밤 버전은 같은 샘플에 리버브 축소·피치 −1반음 |
| **띵** (전자레인지) | **유인 도구** — 파문 400을 만들고 적을 부른다 | 1.2초 감쇠, 금속 배음 중심(가안 2.4kHz), 뒤에 전자부 레귤레이터 잡음 |
| **6:00 종소리** | 아침 = 클리어. 매 판의 카타르시스 | 딸랑과 **같은 음정 계열**의 종(종 3타+잔향 4초) — "일상의 소리가 돌아왔다"를 음악 없이 전달 |

**페이즈 톤 (요약)**: 아침·낮 경영 = 밝은 어쿠스틱(결정 16의 "따뜻한 일상의 밤") / 낮 원정 = 타악+발소리, 실내 진입 시 BGM 정지 / 밤 방어 = 베이스 드론+심박, 3단 강도 레이어 / 새벽 6시 = 종 하나 / 엔딩 = 무음→엔진음→라디오 잡음.

## 1. 톤 기준선 — 무엇을 무섭게 만들고, 무엇을 무섭게 만들지 않는가

| 축 | 이 게임의 선택 | 근거 |
|---|---|---|
| 공포의 발생원 | **상황**(문이 뚫린다·시계가 간다·사람이 죽는다) | 아트 결정 16: "공포·그런지 금지, 평범한 밤이 더 무섭다" |
| 공포의 표현 | 기계음의 **미세한 변조**(형광등 60Hz 험의 피치 흔들림, 냉장고 컴프레서 기동) | 07 E-2 FNAF 문법 |
| 감정의 표현 | 전투가 아니라 **관계** — 추모벽·파견·문 두드림에서 음악이 아니라 **정적과 종이 소리** | 피치 §6 "이 게임의 심장" |
| 하지 않는 것 | 비명, 고어, 저역 과다(폰 스피커에서 안 들림), 멜로디가 강한 전투 BGM | 12세 등급 / 모바일 스피커 |

**믹스 기준**: 폰 스피커(소형, 저역 −20dB 이하)를 1순위로 믹스한다. 120Hz 이하는 "느낌"으로만 쓰고, **정보는 300Hz~4kHz**에 싣는다. 이어폰 사용자를 위해 저역 레이어는 별도 버스로 분리(§7).

## 2. 레이어 구조 — 한 장면에 몇 개의 소리가 겹치는가

```
[ L0. 앰비언트 ]  상시. 형광등 험 · 냉장고 컴프레서 · 바람(외부) · 골목 개소리(낮)
      ↓ (L1은 L0를 덮지 않고 '구멍'을 낸다)
[ L1. BGM ]       페이즈별. 8~16마디 루프, 3단 강도 레이어(잔잔/긴장/격전)
      ↓
[ L2. 시스템 SFX ] 시계 이벤트 · 파문 · 문 두드림 · 호드 경보 · 사기 경고
      ↓
[ L3. 전투 SFX ]   타격 · 피격 · 사망 · 바리케이드 · 수리 · 스킬
      ↓
[ L4. UI ]        탭 · 확인 · 구매 · 계산대 스캔 · 화면 전환
      ↓
[ L5. 보이스 ]    없음(전량 텍스트). 유일한 예외 = 라디오 잡음 속 음성(엔딩·시즌 티저) — §5 S-12
```

- **동시 발음 상한 12채널**, L2는 L3보다 항상 +3dB(정보 우선).
- L0는 **끄지 않는다**. 단, 소등의 밤에는 형광등 험을 페이드아웃하고 냉장고만 남긴다 → "불이 꺼졌다"를 소리로 먼저 알린다.
- 전투 격전 시 L1을 −6dB 덕킹(음악이 정보를 가리지 않게). 4:44·5:55 스팅어는 L1을 0.3초 완전 뮤트 후 터뜨린다.

## 3. 페이즈별 사운드 표

### 3.1 아침 — 정산·배급·성장 (D+n 시작)
| 항목 | 내용 |
|---|---|
| BGM | 어쿠스틱 기타+우쿨렐레+전자피아노, BPM 92, 16마디. **라디오에서 흘러나오는 듯한** 밴드패스(300~5kHz) + 살짝 처진 튜닝 — "누군가의 라디오가 아직 켜져 있다" |
| 앰비언트 | 새소리(멀리), 냉장고, 형광등(밤보다 밝은 톤), **딸랑 1회**(매장이 아직 우리 것이라는 확인) |
| 시스템 SFX | 호드 예고 배너(당일=저역 타격 2회 / 전날=1회), 일지 발견(종이 바스락+펜 소리), 카드키 권한 상승(금속 카드 긁힘+전자 비프 2음) |
| 정서 포인트 | **추모 화면이 뜨는 아침은 BGM을 재생하지 않는다.** 종이 넘기는 소리만. 화면 닫을 때 낮은 첼로 한 음(2초) — 32_UI플로우 "추모 열람 사기 +5"의 청각 보상 |

### 3.2 낮 원정 — 지도 이동
| 항목 | 내용 |
|---|---|
| BGM | 타악(낮은 톰·셰이커) 중심, BPM 112, 멜로디 최소. **햇빛 예산이 줄수록 레이어가 하나씩 빠진다**(긴장의 청각화) |
| 앰비언트 | 골목 바람, 멀리 개, 까치, 전선 위 새 — 도시가 **비어 있다**는 소리 |
| 시스템 SFX | 노드 이동(발소리 3~4보), 수색 완료(지퍼), 가방 가득 참(천 긴장), 일몰 경고(낮은 사이렌 1회, 60초 전) |
| 실내 진입 | **BGM 즉시 정지**(0.2초 페이드) → 손전등 스위치 "딸깍" → 심장박동(60→80bpm) → 좀비 근접 시 **숨소리만**. 30_GDD §3 "실내=어둠 속 교전 지역"을 소리로 구현 |
| 좌초(일몰 초과) | 모든 소리 뮤트 1.5초 → 낮은 드론 → 원정 실패 스팅어 |

### 3.3 밤 방어 — 03:00~06:00 (420초, 실측 타이밍은 §4)
| 항목 | 내용 |
|---|---|
| BGM | 베이스 드론 + 심박 kick(60→72bpm, 밤이 깊을수록 상승). 3단 레이어: **Lv1 배회**(드론만) / **Lv2 긴장**(+아르페지오 16분) / **Lv3 격전**(+브라스 스탭·스네어). 레이어는 웨이브 강도로 자동 크로스페이드 |
| 앰비언트 | 형광등 험(피치 −2반음, 밤 톤), 냉장고 컴프레서(기동/정지 주기 = 긴장의 박자), 셔터 너머 바람 |
| 시스템 SFX | 웨이브 시작(북 1타), 거점 붕괴(철제 찢어짐 — 고어 아님, **금속**), 바리케이드 갉기(나무 긁힘 루프, 내구도 낮을수록 음정 상승), 수리(드라이버·망치 2종), 파문 발생(§5 S-06), 문 두드림(§5 S-07), 호드 밤 시작 경보 |
| 전투 SFX | §5 S-08~S-10. 타격은 **재료별 3계열**: 비닐(편의점 물품) / 둔기(빠루·파이프렌치) / 금속(화기·도끼) |
| 사기 | 40 미만 = 심박에 불규칙 1타 추가 / 20 미만 = 저역 드론 + 화면과 함께 **호흡 소리** / 80 이상 = BGM에 밝은 벨 1음(무의식적 보상) |
| 소등의 밤 | 형광등 험 OFF, 냉장고만, BGM −8dB, 대신 **바깥의 발소리가 선명해진다**(웨이브 −70%의 청각적 근거) |

### 3.4 시계 이벤트 — 이 게임의 심장 (실측 초)
| 시각 | 게임 내 초 | 사운드 설계 |
|---|---|---|
| 03:00 시작 | 0s | 셔터 내려오는 금속음 → 형광등 "틱틱" 2회 점등 → 험 시작. **딸랑은 울리지 않는다**(문이 잠겼다) |
| **3:33 러시** | **77s** | 멀리서 **군중 발소리**가 3초에 걸쳐 커짐 + 북 러시 + BGM Lv2로 강제 상승. 시계 UI와 동시에 "3:33 — 러시!" 배너 |
| **4:44 정예** | **242s** | **먼저 정적 0.8초**(모든 L1·L2 뮤트) → **CCTV 노이즈** 1.5초(화면 지직과 동일 소스) → 금속성 비명 아닌 **고주파 링잉** → 러너 발소리(맨발 아님, 운동화 끄는 소리). 32_UI "CCTV 노이즈로 지직" |
| **5:55 최종** | **408s** | 하늘 밝아지는 **저역 상승 시어** + 전 좀비 광폭화(숨소리 톤 −2반음·빨라짐) + BGM Lv3 고정 |
| **6:00 일출** | **420s** | **종소리**(§5 S-03) 1타 → 잔향 동안 모든 전투음 페이드 → 새소리 · 딸랑 1회 → 클리어. 최후의 저항 성공도 **같은 종**으로 끝난다(성공/일반 클리어 구분은 잔향 길이로만) |
| 최후의 저항 | 거점 3개 붕괴 시 | 30초 카운터 = **심박 140bpm + 관악 한 음(지속)**. 실패 시 전음 암전 1.2초 후 무음 → 오버 화면 |

### 3.5 이벤트·연출
| 이벤트 | 사운드 |
|---|---|
| **E1 문 두드림** | 셔터 밖 "톡톡톡"(손바닥 아님, 손등) 3회 → 2초 정적 → 다시 3회, 점점 커짐. **열어준다**: 셔터 모터 15초 + 발소리 + 딸랑(문이 열렸다는 뜻의 변주) / **무시한다**: 두드림이 멎고 **파문 whoosh** + 멀리서 좀비가 몰리는 소리. "…소리가 멎었다" 텍스트와 동시 |
| 추모벽 | BGM 없음. 폴라로이드가 걸리는 **플라스틱 딸깍**, 사진 표면 손끝, 아주 먼 형광등 험. 닫을 때 첼로 한 음 |
| 일지 열람 | 종이 펼침 + 형광등 험 −6dB. 12장 완독 시 **금속 문 잠금 해제 3중 클릭**(카드키 권한 4) |
| 파견 | 문 닫힘 → 발소리 3인이 멀어짐 → 바람. 문구 "우리는 세 사람을 어둠 너머로 보냈다" 동안 무음 |
| 무전기(광고 보상) | 캐리어 노이즈 0.5초 + "치지직… 지원 확인" 처리된 음성(비언어) |
| 심층부(최심부) 개방 | 지하 문 3중 해제 + **전국 지도 램프 점멸**(작은 릴레이 클릭 다수) + 강대식 유언은 텍스트만 |
| 탈출 엔딩 | 4페이지: ① 롤콜 = 무음, 사진 넘기는 소리만 ② 탑승자 명단 = 트럭 시동 ③ 정산 = 엔진 공회전 + 라디오 잡음 ④ 백미러 = **라디오 음성 한 줄**("…이쪽은 인천… 들리면… 3시에 불을…") → 잡음 → 피아노 한 음 → 《다음 등대: 인천공항점》 |
| 시즌 티저(인천공항) | 관제탑 회전등 모터음 1회전 + 활주로 바람 |

## 7. 모바일 최적화 — 무음·저용량·원핸드

### 7.1 무음/오디오 세션 (가장 먼저 지켜야 할 것)
- **무음 스위치를 존중한다.** iOS는 `ambient` 계열로 세션을 잡아 무음 스위치 ON이면 조용히 재생(다른 앱 음악도 죽이지 않음). Android는 포커스 획득 시 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK` 사용.
- **무음 플레이가 정식 지원 경로다** — 정보가 소리에만 있으면 안 된다. v4는 이미 파문 링·시계·경보 배너·"…소리가 멎었다" 텍스트로 시각 대체를 갖고 있다. 사운드 추가 후에도 **무음 30분 완주 테스트**를 QA 항목에 넣는다.
- 전화 수신·다른 앱 전환 시 즉시 덕킹·복귀(`onAudioInterruption`). 백그라운드 재생 없음.

### 7.2 용량 예산 (총 **7MB 이내**, 앱 전체 목표의 3% 이하)
| 자산 | 수량 | 포맷 | 예산 |
|---|---|---|---|
| BGM | 5곡(타이틀·아침·원정·밤3레이어·엔딩) | AAC-LC 96kbps, 44.1kHz 스테레오, 60~90초 루프 | **≤4.0MB** |
| 앰비언트 루프 | 6종(험·냉장고·바람·실내·옥상·벙커) | AAC 64kbps 모노 20~30초 | ≤0.8MB |
| SFX | 90종 | AAC 64~96kbps 모노, 0.05~3초 | ≤1.8MB |
| 스팅어 | 6종(3:33·4:44·5:55·호드·최후의 저항·파문) | AAC 128kbps | ≤0.4MB |
- 1차 로딩에는 **무음**, 게임 시작 후 백그라운드 스트리밍(첫 밤 시작 전까지 L0만 필요).
- 루프는 **샘플 단위 정확 루프**(앞뒤 20ms 크로스페이드 금지 — 험의 위상이 틀어져 '숨 쉬는' 느낌이 죽는다). 루프 포인트 메타데이터 동봉.

### 7.3 원핸드·스피커 환경
- 폰 스피커 기준 믹스(§1). 저역은 100Hz HPF 후 "있으면 좋은" 레이어로만.
- **햅틱 병행**: 타격 0.02s / 바리케이드 붕괴 0.08s / 4:44 0.15s. 소리를 꺼도 손이 먼저 안다(원핸드 세로 화면에서 특히 유효).
- 동시 발음 12채널 풀, 스틸 시 0.05초 페이드(클릭 방지).
- 배터리·발열: 실시간 합성 금지(전부 프리렌더), AudioContext 1개, 백그라운드 정지.

### 7.4 볼륨·접근성
- 볼륨 버스 3개: **BGM / 효과음 / UI**(각 0~100, 10단계). 기본값 BGM 60·효과 85·UI 70.
- 색약·청각 접근성: 모든 경보에 시각 배너 동시 표시(이미 구현), 자막 크기 옵션과 무관하게 라디오 음성은 항상 자막.

## 8. 제작·라이선스 계획 (상용 단계)

| 단계 | 내용 | 기간(가안) |
|---|---|---|

- **납품 규격**: 48kHz/24bit 원본 + 인게임 인코딩본 + 루프 포인트·스템 표가 담긴 큐시트(이 문서 §4를 갱신해 인계).

## 9. v4 코드 접점 (프로토에 바로 꽂을 수 있는 지점)

현재 `docs/gamev4.js`에는 **오디오 코드가 0줄**이다(`AudioContext`·`new Audio`·`.play()` 검색 결과 없음). 사운드는 전부 신규이며, 아래 지점에 훅만 걸면 §4 큐시트가 그대로 동작한다.

| 훅 | 위치(변수·함수) | 걸 소리 |
|---|---|---|
| 밤 시작 | `startNight()` / `CFG.NIGHT_SEC:420` | S-01 시작, 셔터음, 03:00 큐 |
| 3:33 / 4:44 / 5:55 | `ev333`(`night_t>=77`) / `ev444`(`>=242`) / `ev555`(`>=408`) | 러시·CCTV·최종 러시 스팅어 |
| 6:00 클리어 | `night_t>=CFG.NIGHT_SEC` | S-03 종, 전투음 페이드 |
| 파문 | `addRipple(x,y,radius,...)` | whoosh(반경에 따라 음량·피치) |
| 소음 점수 | `noiseScore` 변화 | 미세 저역 럼블(누적 경고) |
| 문 두드림 | `knock` / `knockTap()` (열기·무시 분기, 무시 시 `addRipple(...,320,...)`·`addMorale(-8)`) | S-07 + 분기별 결과음 |
| 바리케이드 | `ENTRIES[].barr.hp` 감소 | S-11 루프(내구도 연동) |
| 최후의 저항 | `laststand` / `lsT=30` / `lsDone` | 심박 140 + 관악 30초, 성공 시 S-03 |
| 거점 붕괴 | `ENTRIES[].barr.hp<=0` | 금속 찢어짐 |
| 사기 | `addMorale()` / `morale` 임계 40·20·80 | 심박 불규칙·드론·벨 |
| 소등의 밤 | `blackout` 토글 | S-01 페이드아웃, 발소리 강조 |
| 구출 합류 | `joined.push()` | S-04 딸랑 변주 |
| 추모 | `memorial.push()` → `drawMemorial()` | 무음 + 종이 소리 + 첼로 한 음 |
| 원정 실내 | `indoor` 진입/퇴장 | BGM 정지·손전등 딸깍·심박 |
| 탈출 엔딩 | `drawEnding()` / `endPage` 0~3 | 4페이지 큐(§3.5) |
| UI 전반 | `takeDamage`·`morningTap`·`skillTap` 등 탭 핸들러 | POS "띡" 통일음 |

**구현 순서 제안(프로토)**: S-01·S-03·S-05·S-06 + 3:33/4:44/5:55 스팅어 → 6:00 종 → S-08~S-10 타격 → 나머지. **첫 3시간 투자로 밤 한 판의 80%가 완성**되는 순서다.
