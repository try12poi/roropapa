## 1. 현재 시스템 진단

| 시스템 | 현재 상태 | 문제 |
|---|---|---|
| 레벨업 (밤) | 서연 전용 카드 6종(POOL), 전부 평면 +% | 동료는 성장 없음. 6종이라 3일차부터 중복·지루함 |
| 시그니처 아이템 | 5종, 주인 시너지(base/syn) 고정 | 강화 불가 → 아침에 만질 게 없음. "누가 드는가"만 결정 |
| 콤보 | 배치 조합 4종(협공·엄호·십자포화·요새) | 좋은 뼈대인데 발전이 없음 (1일차 = 10일차) |
| 시설 | 바리케이드·밭 2종 무한 레벨 | 재료 소모처가 얕음. 선택이 아니라 "돈 되면 누름" |
| 구출 생존자 | totalRescued 카운트만 하고 **미사용** | 원정 far 노드의 최대 보상이 공갈빵 |
| 자원 | 식량(유지비), 재료(시설) | 소모처 2개뿐 → 중반부터 재료 남아돎 |

**핵심 결론: 성장 축이 "서연 1인 + 런 한정 카드"뿐이다. 동료·아이템·콤보가 전부 정적이라 3일차 이후 할 "선택"이 없다.**

## 2. 레퍼런스 분석 (유사·인기작)

### 2.1 Vampire Survivors — 무기 진화
- **시스템**: 무기 + 짝 패시브를 만렙 → 진화(완전히 다른 동작). 레벨업마다 3~4택 드래프트.
- **가져올 것**: "이 조합을 모으면 저게 된다"는 **명시적 목표**. 진화는 수치가 아니라 **동작이 바뀜**(우리 에어소프트건→관통탄처럼).
- **주의점**: 진화 레시피가 숨겨져 있으면 모바일에선 그냥 모름. 화면에 레시피 상시 노출 필요.

### 2.2 탕탕특공대 (Survivor.io) — 장비 강화·각성
- **시스템**: 인게임 스킬 드래프트(런 한정) + 장비 강화/합성(영구). 장비는 등급 승급 시 **고유 효과 해금**.
- **가져올 것**: **"런 안 성장"과 "런 밖(우리는 아침) 성장"의 2층 분리**. 아침에 재료로 아이템 레벨을 올리는 루프가 우리 경영 페이즈와 정확히 맞물림.
- **주의점**: 강화 수치 인플레가 심하면 밸런스 조절판(CFG)이 무의미해짐. 아이템 강화는 레벨당 +10~15% 선으로 억제.

### 2.3 Brotato — 상점 경제와 스탯 트레이드오프
- **시스템**: 웨이브 사이 상점. 아이템이 +도 주고 −도 줌(공격↑/체력↓). 캐릭터가 규칙 자체를 비틈.
- **가져올 것**: **희소성이 선택을 만든다**. 아침에 재료가 "다 사기엔 모자라게" 나와야 시설이냐 아이템이냐가 고민이 됨. 스킬 노드에도 트레이드오프 노드 소량 배치(예: 진아 "중배럴": 대미지+40% / 연사−20%).
- **주의점**: 마이너스 노드는 소수만. 전 노드가 트레이드오프면 모바일 유저는 피로함.

### 2.4 Hades — 이중신 축복(Duo Boon)
- **시스템**: 신별 축복 계열 + 두 신을 섞으면 전용 듀오 축복 해금. 빌드에 서사가 생김.
- **가져올 것**: 우리 **거점 콤보 = 듀오 축복의 자리**. 콤보를 스킬트리로 강화(협공Ⅱ, 십자포화Ⅱ)하면 "재혁 트리 + 상철 트리를 같이 찍는 이유"가 생긴다. 캐릭터 관계(스토리)와 성장이 연결되는 게 이 게임 서사 백로그와도 궁합 좋음.
- **주의점**: 콤보 강화는 두 캐릭터 모두 특정 노드를 찍어야 열리게 — 한 명 몰빵을 견제.

### 2.5 Dome Keeper — 낮 채굴 ↔ 밤 방어의 시간 압박
- **시스템**: 자원 캐러 멀리 갈수록 다음 웨이브 준비가 늦음. 업그레이드 트리는 작지만 전부 체감됨.
- **가져올 것**: 우리 원정 예산(햇빛)과 동일 구조. **트리는 작게, 노드는 굵게**: 노드 하나 = 눈에 보이는 변화 1개. "회복 +3%" 같은 노드 금지.
- **주의점**: 없음. 이 게임이 우리 루프의 직계 조상. 규모 감각(캐릭터당 6~8노드)을 그대로 벤치마크.

### 2.6 Darkest Dungeon — 로스터 정체성
- **시스템**: 영웅마다 스킬 7종 중 4개만 장착. 부상·성격이 로스터 관리를 만듦.
- **가져올 것**: 동료가 다운·부상되는 우리 구조에서 **"오늘 밤 누구를 어디에"가 곧 빌드**. 트리 분기는 "역할을 바꾸는 선택"이어야 함(만수를 요새파로 키우면 수리기사, 발명파로 키우면 터렛 설치자).
- **주의점**: 우리 인원은 5명 고정이라 사망 로테이션은 부적합. 대신 분기 리스펙을 싸게(식량 소량) 열어주기.

### 2.7 Backpack Hero / Backpack Battles — 배치가 곧 강화 (보너스 아이디어)
- **시스템**: 아이템을 격자에 "어떻게 놓느냐"가 시너지를 결정.
- **가져올 것(후보)**: 편의점 **진열대 = 격자 인벤토리** 컨셉은 테마 궁합이 완벽. 다만 시스템 하나가 통째로 늘어나므로 v2 이후 검토(§7).

### 종합 — 우리가 세울 3원칙
1. **2층 성장**: 밤 = 휘발성 드래프트(빠른 쾌감) / 아침 = 영구 트리·강화(계획 쾌감). 층을 섞지 않는다.
2. **노드는 동작을 바꾼다**: 티어1은 수치여도 되지만 티어2·3은 반드시 새 동작(관통, 도발, 터렛, 소생).
3. **성장이 관계를 향한다**: 트리 심화가 거점 콤보 강화로 수렴 → 배치 전략·캐릭터 서사와 맞물림.

## 3. 성장 구조 총설계 — "3개의 축"

```
        [밤]  레벨업 드래프트  ← XP젬 (런 중 휘발, 즉석 빌드)
        [아침] 캐릭터 스킬트리  ← 기술포인트 SP (런 내 영구, 분기 선택)
        [아침] 아이템 강화·각성 ← 재료 🔩 (런 내 영구, 경제 선택)
```

### 3.1 새 자원: 기술포인트 (SP)
- **획득**: 밤 생존 시 전원 +1 SP. 밤 처치 30+이면 +1 추가. **구출 생존자 1명 = 전원 +1 SP** (far 원정의 보상 완성 — 미사용이던 totalRescued 활용).
- **소모**: 캐릭터 스킬트리 노드 (티어1=1SP, 티어2=2SP, 티어3=3SP).
- **리스펙**: 식량 5로 캐릭터 1명 초기화 (부담 없게).
- 재료(🔩)는 그대로 시설+아이템 강화 전용 → 자원 역할이 겹치지 않음.

### 3.2 아침 화면 개편
현재 아침 화면에 탭 2개 추가: `[근무] [스킬] [장비]`
- 스킬 탭: 생존자 탭 → 그 캐릭터의 트리(세로 2갈래) 표시. 노드 탭 = 즉시 습득.
- 장비 탭: 기존 아이템 바 + 강화 버튼(🔩 비용) + 각성 조건 표시.

## 4. 캐릭터 스킬트리 (5명 × 2갈래 × 3티어 = 30노드)

> 갈래는 배타 아님 — SP만 있으면 양쪽 다 가능. 단 SP 수급(밤당 1~2)상 자연히 한쪽 특화가 됨.
> 티어3은 해당 갈래 티어1+2 선행 필요.

### 서연 (주인공 · 간호사) — 「응급실」 vs 「야간조」
| | 응급실 (지원) | 야간조 (전투) |
|---|---|---|
| T1 | **넓은 처치범위**: 치료 반경 100→140 | **묵직한 손목**: 빠루 대미지 +8 |
| T2 | **아드레날린**: 치료 중인 동료 공속 +20% | **부위 파괴**: 15% 확률 좀비 2초 기절 |
| T3 | **소생술**: 다운 동료에 3초 접촉 시 즉시 기상(밤당 2회) | **트리아지**: 체력 30% 이하 좀비 즉사(처형) |

### 진아 (알바 · 원거리) — 「저격수」 vs 「속사포」
| | 저격수 | 속사포 |
|---|---|---|
| T1 | **조준 훈련**: 사거리 +50 | **가벼운 손놀림**: 연사 +15% |
| T2 | **관통탄**: 직선상 좀비 2체 관통 | **도탄**: 처치 시 근처 좀비에 50% 대미지 튕김 |
| T3 | **헤드샷**: 4번째 발마다 대미지 3배 | **제압사격**: 명중 좀비 이동속도 −30% (2초) |

### 재혁 (소방관 · 근접딜러) — 「진압」 vs 「돌파」
| | 진압 (광역) | 돌파 (단일) |
|---|---|---|
| T1 | **넓은 스윙**: 공격이 부채꼴 광역화 | **완력**: 대미지 +10 |
| T2 | **소화 분사**: 8초마다 전방 분사 — 좀비 3체 넉백+슬로우 | **파고들기**: 첫 타격 대상에 대미지 +50% |
| T3 | **역화**: 넉백된 좀비끼리 충돌 시 추가 대미지 | **구조 우선**: 다운 동료 근처에서 대미지 +40%·피해 −30% |

### 상철 (사장님 · 탱커) — 「철벽」 vs 「물류」
| | 철벽 | 물류 |
|---|---|---|
| T1 | **맷집**: 최대체력 +40 | **알뜰함**: 좀비 식량 드랍률 10%→16% |
| T2 | **도발**: 거점 반경 내 좀비가 상철을 우선 공격 | **핸드트럭 돌진**: 10초마다 직선 돌진 — 경로상 좀비 넉백 |
| T3 | **버티기**: 치명상 시 1회 체력 1로 생존+3초 무적 (밤당 1회) | **재고 정리**: 밤 종료 시 파티 XP젬 +30% 정산 |

### 만수 (설비기사 · 수리) — 「요새」 vs 「발명」
| | 요새 | 발명 |
|---|---|---|
| T1 | **보강 용접**: 수리량 +6/초 | **손재주**: 밤 시작 시 재료 +1 |
| T2 | **가시 철조망**: 만수 배치 거점 바리케이드가 갉는 좀비에 초당 반사 대미지 | **자동 터렛**: 배치 거점에 소형 터렛 1기 설치(대미지 8, 사거리 150) |
| T3 | **이중 셔터**: 배치 거점 바리케이드 파괴 시 1회 50% 내구도로 재생성 | **CCTV 개조**: 모든 거점 좀비 접근을 미니맵에 표시 + 원거리 동료 첫 타 대미지 +25% |

### 설계 노트
- **T1 = 수치, T2 = 새 동작, T3 = 밤당 제한부 강력 효과** — Dome Keeper식 "전부 체감" 원칙.
- 만수 트리는 기존 요새 콤보·수리 AI(gamev2.js의 mansu 분기)에 그대로 얹힘. 터렛만 신규 엔티티.
- 트레이드오프 노드(Brotato식)는 v1엔 미포함 — 노드 30개 밸런스가 먼저.

## 5. 아이템 강화 · 각성

### 5.1 강화 (아침 · 재료 소모)
- 아이템별 **Lv.0→3**. 비용 🔩 3/5/8. 레벨당 base·syn 효과 +25%p씩 상승.
- 예) 소화기 Lv.2: base dmg 8→12, syn 16→24.
- 시설(바리케이드·밭)과 같은 재료를 쓰므로 **아침마다 "시설이냐 장비냐"** 선택 발생.

### 5.2 각성 (VS식 진화 — 조건 명시형)
**조건: 아이템 Lv.3 + 주인 장착 + 주인의 트리 노드 4개 이상.** 조건은 장비 탭에 항상 표시.

| 아이템 | 각성명 | 새 동작 |
|---|---|---|
| 빠루 → | **네일 빠루** | 타격 시 30% 확률 출혈(초당 4, 3초) |
| 소화기 → | **산업용 소화기** | 공격이 항상 부채꼴 + 명중 좀비 슬로우 |
| 에어소프트건 → | **개조 카빈** | 관통 1 기본 + 사거리 300 |
| 파이프렌치 → | **유압 렌치** | 수리 2배 + 타격 시 좀비 갉기 3초 중단 |
| 핸드트럭 → | **철판 핸드트럭** | 최대체력 +90 + 전방 피해 20% 경감 |

- 각성은 런당 5개 전부 가능하되 재료·SP 수급상 실제로는 2~3개 → 회차마다 다른 조합.

## 6. 밤 드래프트 · 콤보 연동 개편

### 6.1 드래프트 풀 확장 (POOL 6 → 18)
- 기존 서연 카드 6종 유지.
- **동료 카드 8종 추가**: "전투 배치된 동료"만 카드로 등장 (예: "진아: 이번 밤 연사 +25%", "재혁: 이번 밤 스윙 광역"). 배치가 드래프트 풀을 바꿈 → 배치의 가치 상승.
- **콤보 카드 4종 추가**: 활성 콤보가 있을 때만 등장 (예: "협공 강화: 이번 밤 협공 배율 1.25→1.5"). Hades 듀오 축복 포지션.
- 전부 **이번 밤 한정** — 아침 트리(영구)와 층이 겹치지 않게.

### 6.2 콤보 Ⅱ (트리 수렴 보상)
두 캐릭터가 각각 트리 노드 3개 이상이면 해당 콤보가 Ⅱ로 승급 (배치 화면에 ★★ 표시):
- 협공Ⅱ: 배율 +25% → +40%
- 엄호사격Ⅱ: 근접 동료 받는 피해 −20% 추가
- 십자포화Ⅱ: 옥상 사격이 2체 관통
- 요새Ⅱ: 강화 내구 +40 → +80, 만수 반사 대미지 2배

## 7. 구현 로드맵

| 단계 | 내용 | 규모 |
|---|---|---|
| **P1** | SP 자원 + 5인 트리(데이터 테이블 `SKILLS[]` + 아침 스킬 탭 UI) + T1 수치 노드만 활성 | 중 — 기존 applyItem/recomputeCombos 패턴 재사용 |
| **P2** | T2·T3 동작 노드 (기절·도탄·돌진·터렛·소생) | 대 — 신규 메커닉 5~6개 |
| **P3** | 아이템 강화 Lv + 각성 | 소 — ITEMS에 lv 필드, applyItem 배율만 |
| **P4** | 드래프트 풀 확장 + 콤보Ⅱ | 소~중 |
| 이후 | 진열대 격자 인벤(Backpack식), 메타 진행(회차 간 영구 해금) | 별도 기획 |

- 트리 데이터는 ITEMS처럼 **선언형 테이블 1개**로: `{id, owner, tier, branch, nm, desc, apply(ent)}`. recomputeCombos()가 이미 "리셋→아이템 적용" 구조라 "→스킬 적용"만 한 줄 끼우면 됨.
- P1만으로도 "아침에 할 선택"이 생겨 루프가 완성됨. P2부터가 재미의 본체.

## 8. 리스크 / 열어둔 질문
1. **SP 수급 밸런스**: 밤당 1~2 SP × 10일 생존 ≈ 15SP. 풀트리(캐릭터당 12SP×5=60SP)는 불가능 → 의도된 희소성. 너무 짜면 far 원정 SP 보상 상향으로 조절.
2. **터렛·돌진 등 신규 엔티티**: 모바일 성능(현재 싱글 캔버스 즉시 렌더)에서 문제 없을 규모인지 P2 때 프로파일.
3. **메타 진행(회차 간 영구 성장)**: 이번 기획은 전부 "런 내 영구". 회차 간 성장(탕탕특공대식)은 게임 오버 빈도 데이터 보고 결정.
